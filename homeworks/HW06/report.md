## 1. Dataset

В качестве исходных данных использовался файл S06-hw-dataset-01.csv. Датасет содержит 12000 строк и 30 столбцов.

Целевая переменная: target - бинарная переменная (значения 0 и 1). Распределение классов демонстрирует умеренный дисбаланс: класс «0» составляет примерно 67.66%, а класс «1» — около 32.34%.

Описание признаков:

Числовые атрибуты: 24 признака, обозначенные как num01–num24.
Категориальные / порядковые атрибуты: группа полей, включая cat_contract и tenure_months.

## 2. Protocol

- Разделение данных: Выборка разделена на обучающую и тестовую части в пропорции 75% к 25% соответственно. Для обеспечения воспроизводимости использован параметр random_state=42.

- Подбор: CV - кросс-валидация на train: нужна для подбора гиперпараметров без доступа к тесту. В работе было 5 фолдов. С помощью оценки cv проводилась оптимизация моделей.

- Метрики: accuracy, F1, ROC-AUC. Есть наличие вероятностей, поэтому уместно использование этих метрик.

## 3. Models

Были исследованы следующие модели машинного обучения:

- DummyClassifier (базовая линия): Простая стратегия (например, stratified) для установления минимального порога качества. Гиперпараметры не подбирались.

- LogisticRegression (линейная модель): Поскольку логистическая регрессия чувствительна к масштабу данных, она использовалась в конвейере (Pipeline) с предварительной стандартизацией (StandardScaler). Основной настраиваемый гиперпараметр — сила регуляризации C (обратная зависимость: меньшее значение C соответствует более сильной регуляризации и более простой модели).

- DecisionTreeClassifier (решающее дерево): Для борьбы с переобучением и контроля сложности дерева подбирались параметры max_depth, min_samples_leaf и ccp_alpha (параметр cost-complexity pruning, штрафующей за сложность структуры дерева).

- RandomForestClassifier (ансамбль на основе бэггинга): Подбор был направлен на ключевые параметры ансамбля: n_estimators (количество деревьев), max_features (количество признаков для рассмотрения при разделении, увеличивает разнообразие деревьев), а также ограничения на глубину и размер листьев для каждого базового дерева.

- HistGradientBoostingClassifier (градиентный бустинг): Использовалась эффективная реализация бустинга. Настройка включала параметры: learning_rate (темп обучения), max_depth и max_leaf_nodes (сложность деревьев-базисов), а также активирован ранний останов (early_stopping=True) для предотвращения 
переобучения.

Для моделей (DecisionTreeClassifier, RandomForestClassifier, HistGradientBoostingClassifier) подбор гиперпараметров осуществлялся с помощью единой функции, реализующей GridSearchCV.

- Сохранение артефактов эксперимента в artifacts/. После выполнения этой ячейки можно открыть папку artifacts/ и увидеть: metrics_test.json (итоговые метрики), search_summaries.json (лучшие параметры подбора).

Графики сохранены в artifacts/figures/.

## 5. Analysis

- Устойчивость:  если поменять `random_state` (хотя бы 5 прогонов для 1-2 моделей) – кратко. В начале работы мы фиксируем RANDOM_STATE, чтобы случайные компоненты были воспроизводимыми. При изменении `random_state` будет необходимо перезапустить обучение для каждой модели. В противном случае у моделей будут отличаться данные, необходимые для опоры на них. Тогда при запуске моделей увеличится количество ошибок - данные будут совпадать случайным образом.

- Анализ ошибок: Матрица ошибок для HistGradientBoosting показывает сбалансированное количество ошибок обоих типов (FP и FN), что согласуется с высокими значениями F1-score и ROC-AUC, и подтверждает эффективность модели на дисбалансированных данных.

- Интерпретация модели: Для определения наиболее значимых признаков использовался метод permutation importance на тестовой выборке. Анализ показал, что наибольший вклад в предсказательную способность модели вносят около 10-15 признаков (топ из них визуализирован на графике в артефактах). Это позволяет сделать выводы о природе данных и может быть использовано для дальнейшего сокращения размерности признакового пространства без существенной потери качества.



## 6. Conclusion

- Для решающего дерева ключевым направлением улучшения является контроль сложности модели за счет ограничения глубины (max_depth), увеличения минимального числа объектов в листе (min_samples_leaf) и применения обрезки (ccp_alpha).
- В случайном лесе повышение устойчивости и качества достигается за счет ансамблевого эффекта: большое количество деревьев (n_estimators) снижает дисперсию, а их разнообразие (управляемое через max_features и ограничения сложности) снижает переобучение.
- Градиентный бустинг (HistGradientBoosting) продемонстрировал наивысшую предсказательную силу на данном датасете, что характерно для многих современных задач.
-  честного протокола оценки (строгое разделение на train/val/test, использование кросс-валидации для подбора, финальная проверка на отложенной тестовой выборке) обеспечивает корректность сравнения моделей и достоверность полученных результатов, минимизируя риск оптимистичной оценки.
